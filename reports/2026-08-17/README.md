# Case Analysis Reports

This folder contains the case-analysis reports produced between 2026-08-15 and
2026-08-17 from the local analysis workspace.

Included:

- Markdown case reports and daily bad-case summaries.
- Self-contained HTML dashboards and test summaries when available.

Intentionally excluded:

- Raw `case-data` traces, tool-call JSON, and downloaded media.
- Local-only evidence paths and private runtime credentials.

Some Markdown reports reference evidence files that remain in the local
analysis workspace and are not part of this public report bundle. The source
reports are preserved as generated so their conclusions and evidence tables
remain auditable.
