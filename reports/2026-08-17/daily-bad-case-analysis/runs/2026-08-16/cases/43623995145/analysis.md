# Case 43623995145

## 结论

- 优先级：P1
- 归因：mixed，执行实现与交付验收共同造成
- 数据来源：production Postgres database 3；348 条消息、82 次工具调用、19 个资产，completeness gate 通过。

## 1. 重建用户意图

用户要求把 Shih Tzu 固定成雕像一样不动，只让前臂/肩部的黑色毛发线条沿手臂像传送带一样运动，并且从慢速逐步加速到快速。线条必须贴合手臂，不能越出身体。

## 2. 时间线与关键证据

- 初始图像分析发现原图肩部已有异常黑线和胸背带文字伪影。
- 第一次 overlay QA 明确指出线条不是自然毛发，越过手臂延伸到地面，且遮罩没有贴合手臂。
- 后续 tight 版本仍被 QA 指出线条压到背带并延伸到肩部以下。
- shih_tzu_hair_fast 的最终检查明确给出三项否定：不是从第一帧就快速运动、狗没有保持完全静止、线条没有全程快速移动。
- 后续 spread 版本仍被检查为规则网格/人工图形，与自然毛发不一致，并有越出身体轮廓的情况。

## 3. 根因判断

实现采用矩形容器和 clip-path 覆盖摄影图，没有建立随手臂轮廓变化的 subject-bound mask。动画速度也只写入 GSAP 时间线，没有通过多个时间点验证慢到快。更严重的是，QA 已经发现遮罩、静止状态和速度问题，交付流程仍将结果送入 show_final_video。

## 4. 影响

用户想要的是局部、自然、可控的毛发运动，实际结果同时出现人工网格感、遮罩越界和主体移动，核心视觉效果失真。该问题直接破坏主体一致性和动作要求，因此为 P1。

## 5. Skill、工具链与媒体限制

trace 中读取了 Motion/HTML 参考，并使用了 write_file、edit_file、lint_composition、render、analyze_file_content 和 show_final_video。问题不是没有工具，而是读到 QA 结果后没有阻断交付。Bad 二进制缓存已失效，不能重跑 ffprobe、blackdetect、freezedetect、音频和九帧；P1 依据来自多次工具 QA 与资产 lineage。

## 6. 待确认 Phase B

增加身体轮廓绑定的遮罩/分割证据；用首帧、中段、末帧验证狗姿态恒定；用多时间点测量线条速度；任何越界、人工网格或速度未达标都阻止交付。未经用户确认不执行改动。
