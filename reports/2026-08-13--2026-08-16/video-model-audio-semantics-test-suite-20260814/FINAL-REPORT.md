# 四模型声音控制口播测试报告

测试日期：2026-08-14

## 结论先行

这轮 12 条原生 API 实测证明，视频模型的声音输入至少要拆成三种能力，不能只封装成一个 `audio_url`：

1. **原音驱动**：H3 和 Wan 能较高程度保留输入音频；Seedance 2.0/2.5 会明显重构声音。
2. **音色参考**：四个模型都说出了 Prompt 指定的新台词，而不是复述参考音频。Seedance 2.0、Seedance 2.5 和 Wan 的音色参考影响明显；H3 有影响，但和 Prompt-only 的差距较小。
3. **Prompt 直出**：四个模型都能只靠 Prompt 正确生成目标普通话台词。

没有任何模型在原音驱动场景同时满足“高保真保留原声 + 严格逐音素口型 + 人物稳定”。因此本轮不能把任何一个模型标记为严格 lip-sync 模型。

## 统一条件

- 同一张卡通人物正面图
- 同一句目标台词：`今天我们测试声音、口型和人物是否稳定。`
- 6 秒、16:9、720p；H3 使用最接近的 768P
- 无字幕、音乐、音效、额外人物、切镜或运镜
- `exact_speech` 上传目标台词音频
- `voice_reference` 上传内容不同的音色样本，Prompt 指定新台词
- `prompt_only` 不上传音频，只描述明亮自然的成年女声
- Seedance 使用火山方舟，H3 使用 MiniMax 中国区官方接口，Wan 使用 DashScope；正式结果不经过 FAL 模型或文件中转

## 三种模式怎么判

### 1. 原音驱动

- **H3、Wan**：适合作为“尽量保留上传声音”的候选。两者都保留了台词和主要波形，但没有完成严格口型合同。
- **Seedance 2.0**：保留了部分声音结构，但输出已经明显重构，不能标记为原音透传。
- **Seedance 2.5**：波形相关性最低，属于按参考和 Prompt 重新生成声音，不适合承诺原声保留。

严格口型方面：H3 和 Seedance 2.0 出现发声期间嘴部停住或只在少量固定口型间切换；Wan 在约 2.2-3.7 秒明显停嘴，后段还有冻结。Seedance 2.5 的口型自然度最好，但仍只是卡通简化口型，不能证明逐音素同步。

### 2. 音色参考后说新台词

四个模型都正确忽略了参考音频的文字内容，并说出新台词。这说明 `reference_audio` 至少能被模型当作声音参考，而不是只能复述。

- Seedance 2.0：90 vs 30，参考影响很强。
- Seedance 2.5：80 vs 35，参考影响明显。
- MiniMax H3：87 vs 72，参考结果更接近样本，但 Prompt-only 本身也较接近，证据强度低于其他三家。
- Wan 3.0：90 vs 25，参考影响很强。

这仍不等于可对外承诺“音色克隆”。正式能力需要换用更有区分度的音色样本，并至少重复三次。

### 3. 仅 Prompt 控制台词和声音

四个模型都完整说对目标句，且没有额外台词、音乐、音效或重叠人声。Seedance 2.0、Seedance 2.5、H3 的连续视频检查达到自然近似口型；Wan 的逐秒视频理解超时，只能确认抽帧中嘴型有变化，不能确认连续同步。

## 对字段封装的直接结论

输入必须显式区分：

```yaml
speech:
  mode: exact_speech | voice_reference | prompt_only | none
  audio_asset: optional
  expected_transcript: optional
  audio_policy: preserve_original | allow_regeneration
  lip_sync_requirement: strict | natural | none
  voice_description: optional
```

输出回执不能只写“生成成功”，至少要拆成：

```yaml
speech_receipt:
  transcript_match: true | false | unknown
  extra_speech: true | false | unknown
  audio_preservation: high | partial | regenerated | unknown
  voice_reference_effect: strong | moderate | weak | unknown
  lip_sync: strict | natural | failed | unknown
  identity_stability: pass | partial | failed | unknown
  freeze_intervals: []
```

`reference_audio` 只是 Provider 输入形状，不能代替业务语义。是否原音保留、是否音色参考、是否严格口型，必须由上层字段和生成后验收共同决定。

## 局限与下一轮

- 当前每个模型每种模式只有 1 条，不能衡量稳定性。
- 卡通人物只有少量离散嘴型，不适合证明逐音素准确度；下一轮应加入真人或高细节数字人素材。
- 3 条视频理解请求超时，改用六宫格检查人物和构图，口型连续性明确记为无法确认。
- 音色相似比较是模型感知分数，不是声纹鉴定。
- `voice-reference-b.wav` 和 30 秒多语言音频已准备，但未进入核心矩阵。H3/Wan 的参考音频上限为 15 秒，30 秒不能直接做四模型同条件比较。

下一轮最有价值的不是继续扩模型，而是对“音色参考”使用一段明显低沉、厚实、与 Prompt-only 女声差异很大的样本，每模型重复 3 次；对“严格口型”改用音素边界明确的短句和高细节人脸。
