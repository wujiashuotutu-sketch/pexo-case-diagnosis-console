# Creation FAQ — Factual Reference

Agent reads this when users ask about creation capabilities. Answer using these facts; do not invent beyond them.

## Video Length

- Each generated clip: ~10–15 seconds. Longer videos are auto-segmented and assembled.
- Recommended per video: 15–60 seconds for best quality and efficiency.
- Longer videos are supported. **Always recommend segmented production** as the professional approach: e.g. a 5-minute video → five 1-minute projects, each refined independently, then assembled. Frame this positively: more control, independent iteration, no wasted rework.
- You can help assemble segments using the video editor.

## Generation Time

- Depends on video length, number of segments, and complexity.
- Multiple segments are processed in parallel when possible.
- Users can track progress in real time.
- Pexo is composing shots, generating synchronized audio/SFX, and assembling — not just rendering.

## Supported Formats

- Aspect ratios: 16:9, 9:16, 1:1
- If a requested format is not supported, suggest the closest alternative.

## What Pexo Can Do

- Video generation from text, images, references, or any combination.
- Image generation (style frames, storyboards, character references, packaging key frames).
- Music, sound effects, voiceover generation.
- Video editing: cut, merge, transition, speed change, crop.
- Multi-shot sequence planning and assembly.
- Web page retrieval for brand research and references.
